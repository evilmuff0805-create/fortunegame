# tasks/dogfooding.md — 도그푸딩 피드백 로그

> 7일(이상) 실기기 도그푸딩 중 발견한 것을 **고치지 않고 모으는** 파일.
> 운영: 발견 즉시 한 줄 추가(날짜·스크린샷 파일명 같이). 사용자가 "테스트 끝났어!" 선언 시
> 이 목록을 우선순위 매겨 한 번에 정리 → 해당 항목을 v1 마감 / v2 백로그로 분배.
> 원칙: 도그푸딩 중에는 수정·기능추가 보류 (검증 흐름 안 끊기게).

기준 문서: 점신PLAN.md(비가역 결정 D1~D11), 골격가이드.md, todo.md

---

## 분류 표기
- **[BUG]** 명백한 결함 — 무조건 고침 (v1 마감 1순위)
- **[튜닝]** 수치·밸런스 조정 — 비가역 골격은 안 건드리고 가역 수치만
- **[개선]** 있으면 좋은 것 — 우선순위 판단 후
- **[v2]** v1 범위 밖 — v2 백로그로 이관
- 각 항목: 상태(🔲미정리 / ✅반영 / ⏸️보류), 발견일, 관련 결정/문서

  - 레버A: jitter 폭 ±12 → ±20~25 (같은 등급 내 분산↑ → 반전 허용)
  - 레버B: 등급 간 base 대비 확대 / 가끔 한 카테고리 스파이크 (포인트 데이)
  - **D6 안전장치**: 좋은 쪽 스파이크는 크게, 나쁜 쪽은 완만하게 (비대칭) — 하락이 불안으로 안 읽히게
